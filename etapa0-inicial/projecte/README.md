# TechShop · Botiga en Línia per a Terminal

Aplicació didàctica de gestió d'una botiga en línia desenvolupada en **Java 25**.

> ⚠️ **Document en construcció:** Aquest fitxer s'ha de completar durant l'**Etapa 1 (Tasca 2)** afegint la descripció completa del projecte, les captures de pantalla en text, les instruccions d'execució i l'índex de documentació.

## Execució Ràpida

Des de l'arrel del repositori:

```bash
java projecte/Main.java
```
